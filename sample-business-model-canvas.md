## How to Create in PowerPoint

1. **Create new slide** with blank layout
2. **Insert 9 text boxes** using Insert > Text Box
3. **Position them** to match the business model canvas layout above
4. **Copy the content** from each section above into corresponding text boxes
5. **Format consistently** with the same font and bullet style
6. **Save to OneDrive/SharePoint** for Microsoft Graph access

## Expected Import Result

When imported, this will create:
- Canvas Name: "TechCorp AI Platform - Business Model Canvas"
- 9 sections with realistic business model content
- Interactive 2D and 3D visualization
- AI chat analysis capabilities

## File ID Instructions

After saving to OneDrive:
1. Open the file in OneDrive web interface
2. Copy the file ID from the URL (usually a long alphanumeric string)
3. Use this ID in the PowerPoint Import dialog
